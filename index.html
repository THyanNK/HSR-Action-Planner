崩铁排轴使用教程

按顺序配置角色、敌人和行动效果，右侧行动轴会实时刷新。

1. 设置我方角色和敌人

在“我方站位与速度”中输入角色名或从候选里选择角色，填写面板速度、百分比加速和固定加速，最终速度会自动计算。

在“敌人行动”里填写敌人名称与速度，点击“+ 敌人”可以增加敌人，敌人在行动轴中会用红色显示。

2. 配置行动上限和转面

页面右上角的 150、300、600 用来切换行动轴显示上限。

“转面设置”支持按固定行动值 或 第 N 个行动后进入下一面，启用“分列”可按面显示行动轴。

3. 特殊设置：翁瓦克、拉条和阿哈

开启角色行里的“翁瓦克”后，第一面首动会提前40%。

开启“拉条”后，该角色会拥有拉条队友的能力，可以选择默认目标和比例，也可以在行动轴中调整。

队伍里有欢愉命途角色时，阿哈时刻会自动显示并加入行动轴。

4. 舞舞舞、推拉条

把右侧“舞舞舞”拖到行动轴某一行，可以在该行动后触发全队拉条。

把“拉条”或“推条”拖到角色或敌人行动上，可以调整那一次行动；数值可直接在行动轴行内修改。

5. 配置保存、导入导出、分享

配置会自动保存到本地浏览器缓存，也可以导出 JSON、导入 JSON 或生成分享链接。
