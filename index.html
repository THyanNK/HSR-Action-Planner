使用教程

按顺序配置角色、敌人和行动效果，右侧行动轴会实时刷新。

1. 设置我方角色和敌人

在 “我方站位与速度” 中输入角色名或从候选里选择角色，填写面板速度和百分比加速，最终速度会自动计算。

在 “敌人行动” 里填写敌人名称与速度，点击 “+ 敌人” 可以增加敌人，敌人在行动轴中会用红色显示。

2. 配置行动上限和转面

页面右上角的 150、300、600 用来切换行动轴显示上限。

“转面设置” 支持按固定行动值 或 第 N 个行动后进入下一面，启用 “分列” 可按面显示行动轴。

3. 特殊设置：翁瓦克、拉条、风套和阿哈

开启角色行里的 “翁瓦克” 后，第一面首动会提前 40%。

开启 “拉条” 后，该角色会拥有拉条队友的能力，可以选择默认目标和比例，也可以在行动轴中调整。

开启 “风套” 后，非自身回合开大时会让该角色下一次行动提前 25%；同谐角色还可以开启开大后自动触发舞舞舞。

开启 “信使” 后，该角色开大时全队速度 +12%（只按基础速度计算），每人各自持续到自己下一次行动结束；多次开大按层数叠加，行动轴上会标「信使 +12%」。如果开大发生在某角色回合内，他会多留一层到再下一次行动结束。

队伍里有欢愉命途角色时，阿哈时刻会自动显示并加入行动轴。

队伍里有「星神★阿哈」时，进战会立刻触发一次阿哈时刻；阿哈开大还会让阿哈时刻提前 20%。

4. 大招、额外回合、舞舞舞、推拉条

开启 “详细行动” 后，行动轴中每次我方行动都可以标记为普攻或战技；右侧 “大招” 插件可以拖入行动轴，并选择开大的角色。

把 “额外回合” 插件拖入行动轴，可以选择哪一个角色插队多行动一次；它不影响该角色原本的行动顺序。

真珠开大时，如果队伍四名角色都是欢愉命途，会自动插入一次额外回合；默认给真珠之外最靠前的那名角色，行内下拉可以换人。

把右侧 “舞舞舞” 拖到行动轴某一行，可以在该行动后触发全队拉条。“舞舞舞” 是同谐光锥，角色行里只有同谐角色能勾选，其他命途的复选框是灰的。

把 “拉条” 或 “推条” 拖到角色或敌人行动上，可以调整那一次行动；数值可直接在行动轴行内修改。

大招和舞舞舞行内都有 “回合内” 勾选框：两者默认都不勾，按两个回合之间处理；勾上表示这次触发在该行角色的回合内，这个角色不会被这次拉条带走，信使套也会给他多留一回合。

5. 配置保存、导入导出、分享

配置会自动保存到本地浏览器缓存，也可以导出 JSON、导入 JSON 或生成分享链接。

“配置保存”里的下拉框选中哪个方案就立刻切到那个方案，当前有没保存的改动时会先弹提示；保存时不动方案名就是覆盖，改了方案名就是另存为一个新方案。
