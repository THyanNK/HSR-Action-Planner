# HSR Action Planner

A browser-based Honkai: Star Rail action value planner for arranging ally, enemy, pull, support, Aha, and multi-phase timelines.

## 简介

这是一个静态网页版的《崩坏：星穹铁道》排轴计算工具。它可以根据我方角色速度、敌人速度、翁瓦克首动提前、角色拉条、舞舞舞、阿哈时刻和转面规则，实时生成行动轴。

工具不需要后端服务，直接打开 `index.html` 即可使用，也可以部署到 GitHub Pages。

左侧导航栏默认收起，可以用页面左侧的小按钮展开或再次收起。

## 使用方法

### 1. 设置行动轴上限

页面右上角可以选择行动轴显示范围：

- `150`
- `300`
- `600`

启用转面后，每一面的行动值都会从 `0` 重新开始显示。

### 2. 配置我方角色

在“我方站位与速度”区域设置 4 个站位：

- `角色`：输入角色名，或从候选列表中选择角色。
- `面板`：角色面板速度。
- `百分比`：按角色基础速度计算的百分比加速。
- `固定`：固定速度加成。
- `最终`：自动计算出的最终速度。
- `翁瓦克`：开启后，第一面首动按提前后的行动值计算；转面后不再生效。
- `拉条`：开启后，可以选择默认目标角色和默认拉条比例。

同一行动值下，我方角色按站位顺序排序。

可以直接拖动角色行调整站位顺序。

### 3. 配置敌人

在“敌人行动”区域设置敌人：

- 使用面数页签切换当前编辑的一面、二面、三面等。
- 点击 `+ 敌人` 添加敌人。
- 填写敌人名称和速度，工具会自动计算敌人行动周期。

增加转面后，敌人面数页签会自动增加。

### 4. 使用阿哈时刻

当队伍中存在欢愉命途角色时，“阿哈时刻”区域会自动出现，并显示参与计算的角色贡献。

没有欢愉命途角色时，阿哈面板和行动轴中的阿哈行动都会自动隐藏。

### 5. 使用行动轴插件

行动轴右侧有固定的插件方框，可以把插件直接拖到行动轴中：

- `舞舞舞`：拖到行动轴某一行，默认在该行动后全队拉条 `24%`。
- `拉条`：拖到某次角色或敌人行动上，默认 `0%`，用于提前该次行动。
- `推条`：拖到某次角色或敌人行动上，默认 `0%`，用于延后该次行动。

插件数值可以在行动轴对应行内直接修改。

### 6. 设置转面

在“转面设置”区域可以控制多面战斗：

- `启用`：开启转面计算。
- `+ 转面`：增加一次转面，例如一次转面对应一面到二面，两次转面对应一面到三面。
- `固定 AV`：在当前面达到指定行动值时转面。
- `行动位置`：在当前面第 N 个行动后转面。
- `分列`：把转面后的行动轴放到原行动轴右侧，按面分列显示。

转面后角色和敌人会重新从当前面的 `0 AV` 开始计算；阿哈时刻保留上一面的跑条进度，只按剩余行动值进入下一面。

### 7. 行动轴显示

行动轴中会显示：

- 行动顺序
- 角色或敌人头像
- 行动名称
- 行动说明
- 当前面行动值
- 速度列

右上角 `速度` 开关可以控制是否显示最右侧速度列，默认关闭。

### 8. 保存和读取配置

在“配置保存”区域可以：

- 输入方案名称。
- 从下拉框选择已保存方案时，方案名称会自动填入输入框。
- 点击 `加载` 恢复方案。
- 点击 `保存` 存储当前配置；如果方案名没有改，会更新原方案；如果改了方案名，会新建一个方案。
- 点击 `新建` 清空当前方案绑定，下一次保存会作为新方案保存。
- 点击 `删除` 移除方案。

配置保存在浏览器本地存储中，不会上传到服务器。

## 本地运行

这个工具是纯静态页面，可以直接双击打开 `index.html`。

如果希望用本地服务器预览，可以在项目目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 部署到 GitHub Pages

将以下文件提交到 GitHub 仓库：

```text
index.html
app.js
styles.css
character-data.js
assets/
.nojekyll
README.md
```

然后在仓库中打开：

```text
Settings -> Pages -> Build and deployment
```

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

保存后等待部署完成，即可通过 GitHub Pages 链接访问。
