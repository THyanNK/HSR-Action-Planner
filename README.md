# HSR Action Planner

A browser-based Honkai: Star Rail action value planner for arranging ally, enemy, pull, support, Aha, and multi-phase timelines.

## 简介

这是一个静态网页版的《崩坏：星穹铁道》排轴计算工具。它可以根据我方角色速度、敌人速度、翁瓦克首动提前、角色拉条、舞舞舞、阿哈时刻和转面规则，实时生成行动轴。

工具不需要后端服务，直接打开 `index.html` 即可使用，也可以部署到 GitHub Pages。

左侧导航栏默认收起，可以用页面左侧的小按钮展开或再次收起。

## 角色数据

可选角色共 96 名，属性、命途与基础速度抓取自 [nanoka.cc](https://hsr.nanoka.cc/character)（2026 年 11 月）。圆形头像放在 `assets/character/`，立绘放在 `assets/character-art/`，属性与命途图标放在 `assets/element/` 和 `assets/path/`。

## 使用方法

### 1. 设置行动轴上限

页面右上角可以选择行动轴显示范围：

- `150`
- `300`
- `600`

启用转面后，每一面的行动值都会从 `0` 重新开始显示。

### 2. 配置我方角色

在“我方站位与速度”区域设置 4 个站位：

- `角色`：输入角色名，或从候选列表中选择角色；也可以直接点角色头像打开立绘图鉴，按命途 / 属性筛选或搜索后一键更换。
- `面板`：角色面板速度。
- `百分比`：按角色基础速度计算的百分比加速。
- `固定`：固定速度加成。
- `最终`：自动计算出的最终速度。
- `翁瓦克`：开启后，第一面首动按提前后的行动值计算；转面后不再生效。
- `拉条`：开启后，可以选择默认目标角色和默认拉条比例。
- `信使`：开启后，该角色开大时全队速度 `+12%`（只按基础速度计算，不乘面板百分比），每人各自持续到自己下一次行动结束；多次开大按层数叠加。如果这次开大发生在某个角色的回合内，该角色会多留一回合。

部分角色带「行迹自拉条」：阿哈、记忆主首次行动提前 `30%`，丹恒·腾荒首次行动提前 `40%`。这类提前会自动生效，并在行动轴第一动标注「行迹 30%」；和翁瓦克同时开时按加法叠加（上限 100%），第一动会同时标出两者。

同一行动值下，我方角色按站位顺序排序。

可以直接拖动角色行调整站位顺序。

### 3. 配置敌人

在“敌人行动”区域设置敌人：

- 使用面数页签切换当前编辑的一面、二面、三面等。
- 点击 `+ 敌人` 添加敌人。
- 填写敌人名称和速度，工具会自动计算敌人行动周期。

增加转面后，敌人面数页签会自动增加。

### 4. 使用阿哈时刻

当队伍中存在欢愉命途角色时，“阿哈时刻”区域会自动出现，并显示参与计算的角色贡献。

阿哈速度 = 阿哈基础速度 + 各欢愉角色速度 × 系数（20% / 10% / 5% / 2%，按速度从高到低取前 4 名）。

- `有阿哈`：勾选后，阿哈基础速度由 `80` 换成阿哈的 `94`；队伍里选了「星神★阿哈」时会自动勾选，且不可取消。
- `哈专`：勾选「有阿哈」后才会出现，勾选后阿哈基础速度改为 `106`。

这两项会随方案一起保存。没有欢愉命途角色时，阿哈面板和行动轴中的阿哈行动都会自动隐藏。

队伍里选了「星神★阿哈」时，进入战斗会立刻触发一次阿哈时刻（`0 行动值`，之后按周期跑条）；阿哈开大还会让阿哈时刻提前 `20%`（即 `10000 / 阿哈速度 × 20%`）。这两条都会直接体现在行动轴里，大招行的说明会标出「阿哈时刻提前 20%」。

### 5. 使用行动轴插件

行动轴右侧有固定的插件方框，可以把插件直接拖到行动轴中：

- `大招`：拖到行动轴某一行，选择开大的角色；阿哈开大会顺带拉条阿哈时刻。
- `额外回合`：拖到行动轴某一行，选择插队的角色，该角色会多行动一次；不改变它原本的行动顺序。
- `舞舞舞`：拖到行动轴某一行，默认在该行动后全队拉条 `24%`。属于同谐光锥，只有同谐角色的那一栏能勾选，其他命途是灰的。
- `拉条`：拖到某次角色或敌人行动上，默认 `0%`，用于提前该次行动。
- `推条`：拖到某次角色或敌人行动上，默认 `0%`，用于延后该次行动。

插件数值可以在行动轴对应行内直接修改。

行内的 `回合内` 勾选框表示这次触发发生在**上一个行动角色的回合里**（拖在谁的下面就是谁的回合）。大招和舞舞舞都默认**不勾**，也就是按「两个回合之间」处理：信使套所有人各拿一层 `+12%`，下一次行动结束就掉。

勾上 `回合内` 之后：那个角色不会被这次全队拉条带走（他这一动已经打完了），信使套的层数也会多留一回合——他下一动结束不掉层，再下一次行动结束才掉，等于多覆盖一整动；其他角色的层数照旧。

另外，真珠开大时如果队伍里四名角色都是欢愉命途，会自动插入一次额外回合（行动轴上标为「自动」，不占用插件位）。这次额外回合默认给真珠之外的一号位（也就是站位最靠前的其他角色），行内下拉可以换人，但不会给真珠自己。

### 6. 设置转面

在“转面设置”区域可以控制多面战斗：

- `启用`：开启转面计算。
- `+ 转面`：增加一次转面，例如一次转面对应一面到二面，两次转面对应一面到三面。
- `固定行动值`：在当前面达到指定行动值时转面。
- `行动位置`：在当前面第 N 个行动后转面。
- `分列`：把转面后的行动轴放到原行动轴右侧，按面分列显示。

转面后角色和敌人会重新从当前面的 `0 行动值` 开始计算；阿哈时刻保留上一面的跑条进度，只按剩余行动值进入下一面。

### 7. 行动轴显示

行动轴中会显示：

- 行动顺序
- 角色或敌人头像
- 行动名称
- 行动说明
- 当前面行动值
- 速度列

右上角 `速度` 开关可以控制是否显示最右侧速度列，默认关闭。

### 8. 保存和读取配置

在“配置保存”区域可以：

- 在下拉框里直接选择方案就会立刻加载，不需要额外点按钮；如果当前有没保存的改动，会先弹提示确认。
- 输入方案名称后点 `保存`：名称没改就是覆盖当前方案，改了名称就是另存为一个新方案（重名会自动加 `(2)` 后缀）。
- 点击 `新建` 清空当前方案绑定，下一次保存会作为新方案保存。
- 点击 `删除` 移除下拉里选中的方案（会二次确认）。
- `导出当前` / `导出全部` / `导入 JSON` / `分享链接` 用于在设备之间搬运配置。

配置保存在浏览器本地存储中，不会上传到服务器。

## 本地运行

这个工具是纯静态页面，可以直接双击打开 `index.html`。

如果希望用本地服务器预览，可以在项目目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 部署到 GitHub Pages

将以下文件提交到 GitHub 仓库：

```text
index.html
app.js
styles.css
character-data.js
assets/
.nojekyll
README.md
```

然后在仓库中打开：

```text
Settings -> Pages -> Build and deployment
```

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

保存后等待部署完成，即可通过 GitHub Pages 链接访问。
